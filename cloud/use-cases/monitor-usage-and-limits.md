# Monitor usage & limits

> Agent index: [llms.txt](/llms.txt)

Memory usage grows quietly - more users, more ingests, more stored memories. The Usage page puts a project's consumption next to your organization's plan limits so you can see headroom at a glance and act before it runs out.

## The problem

Consumption is invisible until it isn't. Without a single place that shows usage against limits, you find out you crossed a threshold only when a bill lands or requests start getting throttled - long after the growth that caused it.

## How the cloud helps

The Usage page renders this project's request volumes (ingest, search, package, tokens) and storage footprint (stored memories, traces, embedding operations, bytes) as stat cards, above a 30-day request-volume chart. Your organization's plan limits sit right beside the numbers, so the gap between "what we're using" and "what we're allowed" is always in view.

## How it works

Open **Usage** on a project. The plan panel shows your organization's limits with a link into [Billing](/cloud/how-to/billing); the stat cards show live request and storage counts; the chart shows request volume for the last 30 days. No instrumentation to add - the numbers are already there.

info

Plan limits are **organization-wide**, so usage from every project counts against the same allowance. Check Usage per project to find what's driving it.

## Key capabilities

-   **Consumption vs limits** - plan limits render beside live usage, not on a separate billing screen.
-   **Cost drivers at a glance** - ingest, search, and package requests, tokens processed, and storage used, as individual stat cards.
-   **30-day trend** - spot a climbing request-volume line before it compounds.

## Outcomes

You catch a spike while it's still headroom, plan an upgrade deliberately instead of reactively, and avoid the throttle-or-surprise-bill moment entirely.

## Get started

Open [Usage](/cloud/how-to/usage) from your project's sidebar, compare the stat cards against your plan limits, and follow the billing link if you're getting close.
